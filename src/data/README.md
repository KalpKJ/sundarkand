# Text sources

`sunderkand.json` holds the invocation and 60 dohas, 598 verses in all.

| Part | Source | Terms |
| --- | --- | --- |
| Devanagari, invocation to doha 59 | [DharmicData](https://github.com/bhavykhatri/DharmicData), which credits the IIT Kanpur Ramcharitmanas project | Open Database License 1.0, which also covers this file as a derived database |
| Devanagari, doha 60 | Added by hand and compared with [a second online text](https://ramayan.wordpress.com/2006/07/24/sunderkand/) | Tulsidas's text is in the public domain |
| Romanisation | Generated letter by letter from the Devanagari, so it keeps final vowels that speech drops | Part of this database |
| English | F. S. Growse (1836–1893), *The Ramayana of Tulsi Das*, Book V, [1914 printing](https://archive.org/details/rmyanaoftuls00tulauoft) | Public domain |

## Checks

- The Devanagari lines were compared with the second text. Apart from encoding differences, three lines differ: one garbled character (`गर्जा`, doha 25), one line the second text lacks (doha 56), and one word it drops (doha 60).
- The English came from a scan. Its words were compared with a second scan of the same translation, and the remaining differences were reviewed by hand. Footnotes were removed, accents on names dropped and quotation marks rebuilt.
- Nobody has proofread either text against a printed edition. The two online Devanagari texts may share a source.

Growse translates each passage as prose, so the English belongs to a whole passage and not to single verses. His numbering matches the dohas. His wording is kept, including the harsh verse in doha 59.
